A Python program (standard library only, no network) that draws one English newspaper front page summing up the world news of Monday 23 November 2026 — the COP31 climate talks collapsing in Antalya without a fossil-fuel deal, Ukraine saying it sank the Russian corvette Merkury off Libya, Democrats winning their largest US House majority since 1992, Nvidia reinstating Jensen Huang as CEO, South Korea's education minister resigning over AI cheating, and fighting blocking the Ebola response in Congo — and writes it as a deterministic 1024x1024 PNG.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png`. Outside the grader's container, set `MAKEFUN_OUTPUT_DIR` to a writable directory instead: `MAKEFUN_OUTPUT_DIR=out python3 main.py` writes `out/entry.png`. Two runs write exactly the same bytes.
